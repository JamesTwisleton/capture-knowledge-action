# Frontend (`frontend/`)

Next.js front end service for Capture-Knowledge-Action (CKA).

## Overview
- **Framework**: Next.js 15, React 19, TypeScript
- **Port**: `3000`

## Key Commands
- Install dependencies: `npm install`
- Run dev server: `npm run dev`
- Build app: `npm run build`
- Run tests: `npm test`

## Environment Variables
- `NEXT_PUBLIC_API_URL`: URL of the CKA backend service REST API (default: `http://localhost:8080`).

## Structure
- `app/`: Next.js App Router pages and layouts.
- `public/`: Static assets.
